# 三十秒の言霊

30 秒の打鍵で「言葉の魔物」を討つ、ブラウザで遊べる RPG タイピングゲームです。
日本語のローマ字入力に対応しており、`ku` / `cu` / `qu` のような綴りのゆらぎもそのまま打てます。

> このリポジトリは、AI（Claude Code）による実装を前提とした検証用プロジェクトです。

## 遊び方

| 操作 | キー |
| --- | --- |
| 戦闘開始 | `Space` |
| お題を打つ | 英字キー（日本語入力はオフ） |
| ジャンル切替 | `Tab` / `Shift+Tab`、`←` `→`、数字キー `1`〜`4` |
| 大技（短文） | `Enter`（ゲージ 1 本） |
| 奥義（長文） | `Shift+Enter`（ゲージ 2 本） |
| 退却 | `Esc`（報酬なし） |

- **30 秒バトル** … 正しい 1 打鍵ごとに敵へダメージが入ります。30 秒以内に HP を削り切れば突破です。時間切れでも、与えたダメージぶんの経験値と欠片は手に入ります。
- **ジャンル切替** … お題は「学校・社会・自然・食」の 4 ジャンル。入力の途中でも切り替えられます。敵の弱点ジャンルは 1.5 倍、耐性ジャンルは 0.6 倍。ボスは HP が減ると弱点が変わります。
- **お題の長さ** … 通常は単語・一文・短文。打ち切ると長さに応じた追撃が入り、ミスなしなら 1.5 倍です。
- **大技と奥義** … 打鍵でゲージがたまります。大技は短文、奥義は長文。打っている間のダメージが上がり、打ち切ると大ダメージ。大技・奥義の最中に倒すと「トドメ」となり、欠片の報酬が 1.5 倍になります。

### 強化要素

- **キー鍛錬（鍛冶場）** … 戦闘で得た「言霊の欠片」で、キーを 1 つずつ強化します（1 レベルごとにそのキーの打鍵ダメージ +10%）。綴りは自由なので、たとえば `C` を鍛えて「か・く・こ」を `ca` `cu` `co` と打つ、といった育て方ができます。
- **刻印** … 決まった層を初めて突破すると手に入り、好きなキーに刻めます（会心・蓄積・連鎖の 3 種類）。
- **ジャンル熟練度** … そのジャンルのお題を打つほど育ち、ダメージが伸びます。
- **綴りの学習** … ローマ字ガイドは、あなたが実際に使った綴りを覚えて次から表示します。

プレイデータはブラウザの localStorage に保存されます。

## 開発

Node.js 22 以上を想定しています。

```bash
npm install
```

```bash
npm run dev
```

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | 開発サーバーを起動 |
| `npm run build` | 型チェックのうえ `dist/` に本番用ファイルを出力 |
| `npm run preview` | ビルド結果をローカルで確認 |
| `npm test` | 単体テスト（Vitest） |
| `npm run lint` | 静的解析（oxlint） |

`vite.config.ts` で `base: './'` を指定しているため、`dist/` の中身は GitHub Pages などのサブディレクトリ配下にそのまま置けます。

## 構成

技術構成は Vite + React + TypeScript です。ゲームのルールは React に依存しない素の TypeScript で書き、画面はそれを表示するだけにしています。

```
src/
├─ typing/               ローマ字入力の判定（画面に依存しない）
│  ├─ romajiTable.ts     かな → ローマ字の対応表
│  ├─ engine.ts          入力判定とガイド生成（っ・ん の特殊処理を含む）
│  └─ engine.test.ts
├─ game/                 ゲームのルール（画面に依存しない）
│  ├─ balance.ts         数値と計算式。バランス調整はまずここ
│  ├─ battle.ts          1 戦ぶんの進行（ダメージ・ゲージ・大技・ジャンル切替）
│  ├─ enemies.ts         敵データ
│  ├─ rewards.ts         報酬の計算、キー鍛錬、刻印の付け替え
│  ├─ save.ts            保存データ（localStorage）
│  ├─ genres.ts          ジャンルの定義
│  └─ texts/             お題データ（ジャンルごとに 1 ファイル）
└─ ui/                   React の画面（ホーム・戦闘・結果・鍛冶場・遊び方）
```

### お題を増やす

`src/game/texts/` の各ファイルに `['表記', 'よみ']` の形で追記します。読みはひらがな（カタカナも可）で、句読点は入れません。
`npm test` を実行すると、読みに打てない文字が混ざっていないか、長さが区分（単語・一文・短文・長文）に合っているかを自動で確認します。

### ローマ字入力の仕様

- 表にある綴りはすべて受け付けます（例: し = `si` `shi` `ci`、じゃ = `zya` `ja` `jya`、ふぁ = `fa` `fwa`）。
- 拗音は分けて打てます（きゃ = `kya` または `ki` + `lya` / `xya`）。
- 「っ」は次の子音の重ね打ち（`kka` `cca` `qqu` `tchi` など）か、単独の `ltu` `xtu` `ltsu` `xtsu`。
- 「ん」は `nn` `xn` `n'`。後ろが母音・な行・や行以外なら `n` 1 つでも打てます。文末は `nn` などが必要です。

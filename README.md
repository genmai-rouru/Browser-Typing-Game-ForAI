# 幻影討伐部

学校の運動場に現れたゲートから出てくる敵を、タイピングで放つ魔法弾で討つ、ブラウザで遊べる RPG タイピングゲームです。
日本語のローマ字入力に対応しており、`ku` / `cu` / `qu` のような綴りのゆらぎもそのまま打てます。

> このリポジトリは、AI（Claude Code）による実装を前提とした検証用プロジェクトです。
> 現在は画面の骨組みを作り直している途中で、戦闘のルールや各画面の中身は今後変わります。

## 画面

| 画面 | 内容 | 状態 |
| --- | --- | --- |
| 部室 | ステータス、パートナー、部室机・部室鏡への入口 | 骨組み |
| 部室前掲示板 | 討伐依頼を選んで運動場へ出撃。部室机へのボタンあり | 依頼の内容は仮 |
| 運動場 | 戦闘（ウェーブ・ターン制）。結果はダイアログで重ねて表示 | 数値は仮 |
| 体育館 | お題練習 | 準備中 |
| 図書室 | お題ジャンルの入荷、お題セットの変更 | 準備中 |
| 技術室 | キーの強化 | 付け替えは未実装 |
| 購買 | キーの購入 | 準備中 |
| 部室机 | パートナーの選択とステータス | 準備中 |
| 部室鏡 | 詳細ステータス、実力 | 準備中 |

部室・掲示板・体育館・図書室・技術室・購買はタブで自由に行き来できます。
「戻る」（`Esc`）は、その画面を開いた元の画面に帰ります（タブから開いた画面は部室に帰ります）。

## 戦闘の流れ

依頼は「ウェーブ（敵 1 体）＞ ターン」で進みます。1 ターンは次の順です。

1. **コマンドフェーズ** … 直前の経過を確認して、次のターンへ進みます（アイテムは準備中）。
2. **攻撃フェーズ（30 秒）** … お題を打つと、1 打鍵ごとに敵へダメージが入ります。お題を打ち始めた瞬間に、ジャンルごとの MP を消費します。残り 2 秒で敵の次の行動が予告されます。
3. **敵の行動** … 攻撃のときだけ防御フェーズになり、制限時間（お題タイマー）内に防御お題を打ちます。
   - 通常攻撃：打ち切れば回避。未完走なら `D×(1−打ち切り率)×(1−実効防御力)`
   - 強攻撃：打ち切っても `D×25%`。未完走なら `D×(1−打ち切り率÷4)`（防御力は無視）
   - 実効防御力 = 防御力% ×（校正力 ÷ 最大校正力）。タイポのたびに校正力が 1 減ります。

敵を倒すと次のウェーブへ進み、HP と MP は引き継がれます。HP が 0 になると敗北です。
同じ敵に 11 ターン以上かけると「疲労」が付き、攻撃フェーズ中に HP が減り続け、攻撃力も下がります。

## 運動場での操作

| 操作 | キー |
| --- | --- |
| 次のターンへ | `Space` / `Enter`（コマンドフェーズ） |
| お題を打つ | 英字キー（日本語入力はオフ） |
| ジャンル切替 | `Tab` / `Shift+Tab`、`←` `→`、数字キー `1`〜`4` |
| 退却の確認 | `Esc`（表示中は時間が止まる。再開後 0.5 秒は入力無効） |

## 開発

Node.js 22 以上を想定しています。

```bash
npm install
```

```bash
npm run dev
```

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | 開発サーバーを起動 |
| `npm run build` | 型チェックのうえ `dist/` に本番用ファイルを出力 |
| `npm run preview` | ビルド結果をローカルで確認 |
| `npm test` | 単体テスト（Vitest） |
| `npm run lint` | 静的解析（oxlint） |

`vite.config.ts` で `base: './'` を指定しているため、`dist/` の中身は GitHub Pages などのサブディレクトリ配下にそのまま置けます。

## 構成

技術構成は Vite + React + TypeScript です。ゲームのルールは React に依存しない素の TypeScript で書き、画面はそれを表示するだけにしています。

```
src/
├─ typing/               ローマ字入力の判定（画面に依存しない）
│  ├─ romajiTable.ts     かな → ローマ字の対応表
│  ├─ engine.ts          入力判定とガイド生成（っ・ん の特殊処理を含む）
│  └─ engine.test.ts
├─ game/                 ゲームのルール（画面に依存しない）
│  ├─ balance.ts         数値と計算式。バランス調整はまずここ
│  ├─ battle.ts          依頼 1 件ぶんの進行（ウェーブ・ターン・防御フェーズ・MP・疲労）
│  ├─ enemies.ts         敵と討伐依頼のデータ
│  ├─ rewards.ts         報酬の計算、キー強化
│  ├─ save.ts            保存データ（localStorage）
│  ├─ genres.ts          ジャンルの定義
│  └─ texts/             お題データ（ジャンルごとに 1 ファイル）
└─ ui/                   React の画面
   ├─ navigation.ts      画面の一覧と「戻る」の行き先
   ├─ Shell.tsx          タブと「戻る」を備えた共通の枠
   └─ …                  各画面（部室・掲示板・運動場・技術室など）
```

### お題を増やす

`src/game/texts/` の各ファイルに `['表記', 'よみ']` の形で追記します。読みはひらがな（カタカナも可）で、句読点は入れません。
`npm test` を実行すると、読みに打てない文字が混ざっていないか、長さが区分（単語・一文・短文・長文）に合っているかを自動で確認します。

### ローマ字入力の仕様

- 表にある綴りはすべて受け付けます（例: し = `si` `shi` `ci`、じゃ = `zya` `ja` `jya`、ふぁ = `fa` `fwa`）。
- 拗音は分けて打てます（きゃ = `kya` または `ki` + `lya` / `xya`）。
- 「っ」は次の子音の重ね打ち（`kka` `cca` `qqu` `tchi` など）か、単独の `ltu` `xtu` `ltsu` `xtsu`。
- 「ん」は `nn` `xn` `n'`。後ろが母音・な行・や行以外なら `n` 1 つでも打てます。文末は `nn` などが必要です。

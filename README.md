# 幻影討伐部

学校の運動場に現れたゲートから出てくる敵を、タイピングで放つ魔法弾で討つ、ブラウザで遊べる RPG タイピングゲームです。
日本語のローマ字入力に対応しており、`ku` / `cu` / `qu` のような綴りのゆらぎもそのまま打てます。

> このリポジトリは、AI（Claude Code）による実装を前提とした検証用プロジェクトです。
> 現在は画面を作り直している途中で、戦闘のルールや各画面の中身は今後変わります。

## 画面

| 画面 | 内容 | 状態 |
| --- | --- | --- |
| 部室 | ステータス、所持金、同行中のパートナー、各画面への入口 | 骨組み |
| かばんの中 | 持ち物（アイテム・装備・貴重品、種類ごとに 64 スロット）の確認 | アイテムは仮 |
| 部室準備室 | かばんに入りきらないアイテム・装備の置き場（種類ごとに 512 スロット） | — |
| 部室前掲示板 | 討伐依頼を選んで運動場へ出撃。部室机へのボタンあり | 依頼の内容は仮 |
| 運動場 | 戦闘（ウェーブ・ターン制）。16:9 の固定画面で、結果とポーズは画面の上に重ねて表示 | 数値・画像は仮 |
| 体育館 | お題練習 | 準備中 |
| 図書室 | お題セット（最大 10 枠。戦闘の「スキル」で選べるジャンル）の編集、お題ジャンルの入荷 | 入荷は準備中 |
| 技術室 | キーの強化（所持金を使う） | 付け替えは未実装 |
| 購買 | キーの購入 | 準備中 |
| 部室机 | パートナーの編成（前衛支援・後方支援）とステータス | 部員は 1 人のみ |
| 部室鏡 | 詳細ステータス、実力 | 準備中 |

部室・掲示板・体育館・図書室・技術室・購買はタブで自由に行き来できます。
「戻る」（`Esc`）は、その画面を開いた元の画面に帰ります（タブから開いた画面は部室に帰ります）。

## 戦闘の流れ

依頼は「ウェーブ（敵 1 体）＞ ターン」で進みます。1 ターンは次の順です。

1. **コマンドフェーズ** … 左上で直前の経過を確認し、コマンド（攻撃・スキル・サポートスキル・装備・アイテム）を選びます。
   - 攻撃：MP を使わない通常攻撃のお題（短い単語）を打ちます。
   - スキル：お題セットの中からジャンルを選び、そのジャンルのお題を打ちます。お題を 1 つ打ち始めるたびに、ジャンルごとの MP を消費します。戦闘中にジャンルは切り替えられません。1 題分の MP も無いジャンルは選べません。
   - サポートスキル：パートナーの固有スキルを使います。使ってもターンは終わりません。
   - アイテム：1 個使うと、そのターンは攻撃できず、すぐ敵の行動に移ります（予告が無いぶん、防御のお題タイマーが 10% 短くなります）。サポートスキルを使ったターンは、アイテムを使えません。
   - 装備：準備中です。
2. **攻撃フェーズ（基本 10 秒）** … 「攻撃」か「スキル」を選ぶとお題がセットされ、最初の正しい打鍵でタイマーが動き出します（動き出すまでは疲労による HP の減少もありません）。1 打鍵ごとに敵へダメージが入ります。残り 2 秒で敵の次の行動が予告されます。
   - スキルの途中で、次のお題を打ち始めるときに MP が足りなければ、「魔力が足りない！」と表示して攻撃フェーズを強制終了します。敵の行動が攻撃なら、予告を 2 秒表示してから防御フェーズに移ります（非攻撃ならそのままコマンドフェーズへ）。
3. **敵の行動** … 攻撃のときだけ防御フェーズになり、制限時間（お題タイマー）内に防御お題を打ちます。
   - 通常攻撃：打ち切れば回避。未完走なら `D×(1−打ち切り率)×(1−実効防御力)`
   - 強攻撃：打ち切っても `D×25%`。未完走なら `D×(1−打ち切り率÷4)`（防御力は無視）
   - 実効防御力 = 防御力% ×（校正力 ÷ 最大校正力）。タイポのたびに校正力が 1 減ります。

**パートナー** … 前衛支援 1 人と後方支援 1 人を同行できます。パッシブスキルは常に働き、固有スキルはコマンドフェーズの「サポートスキル」から使います。固有スキルは戦闘開始時からクールダウン中で、ターンが終わるごとに 1 減ります。同行したパートナーは戦闘後に経験値を得て、スキルレベル（0〜10）が上がります。

**報酬** … 依頼を達成すると、経験値・討伐報酬金（円）・アイテムが手に入ります。アイテムは、倒した敵のドロップと依頼の報酬（初回限りのものと、達成するたびのもの）です。敗北時は経験値のみ、退却時は何も得られません。入手したアイテムはかばんに入り、入りきらない分は部室準備室に送られます。

敵を倒すと次のウェーブへ進み、HP と MP は引き継がれます（MP は自然には回復しません）。HP が 0 になると敗北です。
同じ敵に 31 ターン以上かけると「疲労」が付き、攻撃フェーズ中に HP が減り続け、攻撃力も下がります。

## 運動場での操作

| 操作 | キー |
| --- | --- |
| メニューの選択 | `↑` `↓` / `W` `S`（マウスを乗せても選べます） |
| メニューの決定 | `Z` / `Enter` / `Space`（クリックでも決定できます） |
| メニューを戻る | `Esc` / `X`（主要コマンドの画面で `Esc` を押すとポーズ） |
| お題を打つ | 英字キー（日本語入力はオフ） |
| ポーズ | `Esc`（依頼名と「再開」「退却」を表示。退却は確認あり。表示中は時間が止まり、再開後 0.5 秒は入力無効） |
| 結果ダイアログ | `←` `→` / `A` `D` で選択（最初は「部室へ戻る」）、`Enter` / `Z` / `Space` で決定、`Esc` で部室へ戻る |

運動場は 1920×1080（16:9）を基準にした固定画面で、ウィンドウに合わせて拡大縮小します。比率が合わない部分は黒帯になります。

### 画像の差し替え

運動場の画像は、`public/images/` に決まった名前で置くと表示されます。ファイルが無いときは仮の表示になります。

| 画像 | 置き場所 | 目安 |
| --- | --- | --- |
| 背景 | `public/images/backgrounds/field.png` | 1920×1080 |
| 敵 | `public/images/enemies/<敵の id>.png` | 透過 PNG、512×512 程度 |
| パートナーの立ち絵（前衛） | `public/images/partners/<パートナーの id>.png` | 透過 PNG、縦長（高さ 1000px 程度） |
| パートナーのアイコン（後衛） | `public/images/partners/<パートナーの id>-icon.png` | 正方形 |

敵の id は `src/game/enemies.ts`、パートナーの id は `src/game/partners.ts` にあります（例：誤字スライム = `goji`、甘井 このみ = `konomi`）。

## 開発

Node.js 22 以上を想定しています。

```bash
npm install
```

```bash
npm run dev
```

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | 開発サーバーを起動 |
| `npm run build` | 型チェックのうえ `dist/` に本番用ファイルを出力 |
| `npm run preview` | ビルド結果をローカルで確認 |
| `npm test` | 単体テスト（Vitest） |
| `npm run lint` | 静的解析（oxlint） |

`vite.config.ts` で `base: './'` を指定しているため、`dist/` の中身は GitHub Pages などのサブディレクトリ配下にそのまま置けます。

## 構成

技術構成は Vite + React + TypeScript です。ゲームのルールは React に依存しない素の TypeScript で書き、画面はそれを表示するだけにしています。

```
src/
├─ typing/               ローマ字入力の判定（画面に依存しない）
│  ├─ romajiTable.ts     かな → ローマ字の対応表
│  ├─ engine.ts          入力判定とガイド生成（っ・ん の特殊処理を含む）
│  └─ engine.test.ts
├─ game/                 ゲームのルール（画面に依存しない）
│  ├─ balance.ts         数値と計算式。バランス調整はまずここ
│  ├─ battle.ts          依頼 1 件ぶんの進行（ウェーブ・ターン・防御フェーズ・MP・疲労）
│  ├─ enemies.ts         敵と討伐依頼のデータ
│  ├─ partners.ts        パートナーのデータとスキルの成長
│  ├─ items.ts           アイテムのデータと、かばん・部室準備室の出し入れ
│  ├─ rewards.ts         報酬（経験値・お金・アイテム）の計算、キー強化
│  ├─ save.ts            保存データ（localStorage）
│  ├─ genres.ts          ジャンルの定義
│  └─ texts/             お題データ（ジャンルごとに 1 ファイル）
└─ ui/                   React の画面
   ├─ navigation.ts      画面の一覧と「戻る」の行き先
   ├─ Shell.tsx          タブと「戻る」を備えた共通の枠（校内の画面）
   ├─ stage/             16:9 の固定画面（GameStage）と画像の差し込み口（GameImage）
   ├─ field/             運動場の部品（コマンド・お題ウィンドウ・ステータス・ポーズなど）
   ├─ FieldScreen.tsx    運動場（戦闘）
   └─ …                  各画面（部室・掲示板・技術室など）
```

### お題を増やす

`src/game/texts/` の各ファイルに `['表記', 'よみ']` の形で追記します。読みはひらがな（カタカナも可）で、句読点は入れません。
`npm test` を実行すると、読みに打てない文字が混ざっていないか、長さが区分（単語・一文・短文・長文）に合っているかを自動で確認します。

### ローマ字入力の仕様

- 表にある綴りはすべて受け付けます（例: し = `si` `shi` `ci`、じゃ = `zya` `ja` `jya`、ふぁ = `fa` `fwa`）。
- 拗音は分けて打てます（きゃ = `kya` または `ki` + `lya` / `xya`）。
- 「っ」は次の子音の重ね打ち（`kka` `cca` `qqu` `tchi` など）か、単独の `ltu` `xtu` `ltsu` `xtsu`。
- 「ん」は `nn` `xn` `n'`。後ろが母音・な行・や行以外なら `n` 1 つでも打てます。文末は `nn` などが必要です。
